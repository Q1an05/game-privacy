一 我们如何使用游戏数据

  • 城市存档：在您游玩、保存或继续游戏时，我们通过 TapTap 提供的本地存储接口，在本机读写地图、道路、建筑、城市经营进度和存档时间，用于保存和恢复游戏。
  • 游戏设置与解锁状态：我们在本机保存音量、静音、显示效果、操作偏好、地图和存档位的解锁状态，用于保留您的选择。
  • 屏幕适配信息：游戏启动或调整显示时，通过平台接口读取屏幕或窗口尺寸、像素比例和安全显示区域，用于画面布局和触摸适配。这些信息在本机使用，游戏代码不将其上报至开发者服务器。
  • 操作信息：游戏在本机处理触摸、拖动等输入，用于执行建造、移动视角等操作。我们未接入向开发者服务器上传操作行为的统计服务。

当前版本不向您索取姓名、身份证号码、手机号码、账号密码、昵称或头像。游戏代码不调用摄像头、麦克风、通讯录、精确位置、相册或剪贴板接口，也不读取广告标识符。TapTap 客户端自身处理的信息见本政策第四节。

二 登录 广告和付费功能

当前版本未配置开发者登录服务地址，不调用小游戏登录接口取得登录凭证，不向开发者服务器传送登录凭证，也不获取 OpenID 或 UnionID 等账号标识。

当前版本未配置激励视频广告位，不创建、加载或播放激励视频广告。游戏界面中保留的广告入口，不代表当前版本已经接入广告服务。当前版本不提供游戏内充值或支付功能。

如果未来版本启用登录、广告、支付或其他涉及个人信息的功能，我们会先更新本政策，说明处理的信息种类、目的、方式、保存期限、第三方服务和权利行使方式，并依法履行告知与同意等义务。

三 数据如何保存和删除

城市存档、设置和解锁状态保存在当前设备的小游戏本地存储中，通常保留至您删除或覆盖数据，或平台、系统清理相应存储时。运行期间使用的屏幕适配信息不作为用户档案上传或保存至开发者服务器。

在游戏中选择“新城市”并确认覆盖已有存档，会替换所选存档位中的城市。覆盖存档不会一并清除独立保存的设置、地图解锁状态和存档位解锁状态。若要清除全部本机数据，请使用 TapTap 客户端或操作系统提供的小游戏数据清理功能；具体入口和可用性以您使用的版本为准。如找不到入口，请通过本政策中的邮箱联系我们。

清除本机数据可能导致城市进度、设置和解锁状态丢失。我们没有这些本机数据的服务器副本，无法为您恢复。我们不通过游戏代码主动将本机存档传输至境外服务器。

TapTap 由易玩（上海）网络科技有限公司提供。您使用 TapTap 账号、平台身份验证、小游戏下载和运行环境等服务时，TapTap 可能依照其政策处理相关信息。这些平台服务不等于开发者已启用小游戏登录或广告。请阅读 TapTap 隐私政策 了解平台处理的信息及权利行使渠道。我们对自身的数据处理活动依法承担个人信息保护义务。

本政策网页使用 GitHub Pages 托管。GitHub 说明，访问 GitHub Pages 网站时，访问者的 IP 地址会因安全目的被记录和保存，无论访问者是否登录 GitHub。本网页没有添加访问统计脚本、广告、外部字体、表单或由我们设置的 Cookie，也不读取您的小游戏存档。请阅读 GitHub Pages 数据收集说明 和 GitHub 隐私声明。

您发送邮件联系我们时，您的邮件服务商和我们的邮件服务商 iCloud Mail 会参与邮件的传输与存储。相关服务的处理规则请参阅您的邮件服务商政策及 Apple 隐私政策。网页托管和邮件服务的数据存储地点及跨境处理规则，详见相应服务商的隐私政策；本机存档的保存方式不代表这些第三方服务也仅在本机处理数据。

五 您主动联系我们时的信息

您通过邮箱咨询、反馈问题或行使个人信息权利时，我们会收到您的发件邮箱、邮件内容，以及您主动提供的附件。我们仅为答复、排查您提出的问题和处理您的请求使用这些信息。请勿在邮件中发送密码、身份证照片或与请求无关的个人信息。截图和日志如包含他人信息，请先遮盖。

我们仅在完成请求所必需的期间保留相关信息；处理目的完成后，依法删除或匿名化处理，法律法规另有保存要求的除外。我们不会出售您的个人信息，也不会将联系内容用于广告营销。除依法履行义务、使用本政策列明的必要邮件服务，或事先依法履行告知及同意等义务外，我们不向其他个人信息处理者提供您的联系内容。

六 您的权利和联系我们

您可以通过 w525691644@icloud.com 联系运营者王谦，询问本政策，或者依法申请查阅、复制、更正、补充、删除我们持有的您的个人信息，撤回同意，或提出投诉。邮件主题可写“城市：崛起 隐私请求”，并说明具体请求。

当前版本没有开发者独立账号，无需注销开发者账号。本机游戏数据按第三节管理；如需管理或注销 TapTap 账号，请通过 TapTap 提供的账号及隐私管理渠道办理。对于您的隐私投诉，您也可以依法向有权受理的主管部门反映。

七 未成年人保护

未成年人应在父母或其他监护人的指导下阅读本政策。我们不通过当前版本主动收集未成年人的身份信息。如后续确需处理不满14周岁未成年人的个人信息，我们会依法制定专门处理规则，取得监护人同意，并采取相应保护措施。监护人发现我们持有其监护的未成年人的个人信息时，可以通过上述邮箱联系我们处理。

八 信息安全

我们按照实际处理的数据及风险采取合理保护措施，限制对联系邮件的访问，并避免索取不必要的信息。请妥善保管设备和平台账号，避免他人访问本机存档。发生个人信息安全事件时，我们会依法采取补救措施，履行通知和报告义务。

九 政策更新

我们会在本页公布政策更新，并注明更新日期和生效日期。涉及处理目的、信息种类、处理方式或您的权利等重大变化时，我们会依法通过适当方式告知；需要取得同意的，会在开展相应处理前依法取得同意。
